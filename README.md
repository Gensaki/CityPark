# CityPark (Projet MOE CDWFS)
## Ville de Montval // Le stationnement, en toute simplicité


CITYPARK — APPLICATION WEB

Pour ouvrir l'application :
1. Décompresser l'archive ZIP.
2. Ouvrir le dossier CityPark_depart.
3. Double-cliquer sur index.html.

Fichiers :
- index.html : structure de la page
- style.css : styles et mise en page responsive
- script.js : données et affichage des parkings

L'application affiche les parkings municipaux, les places disponibles,
une recherche par nom ou adresse et un tri.
